# 하드웨어 핀맵 및 배선 결선 가이드 (Pinout & Wiring Guide)

---

## 1. ESP32-CAM + L9110S (또는 L298N) 올인원 결선

### [ESP32-CAM ↔ 모터 드라이버]
| ESP32-CAM 핀 | 모터 드라이버 (L9110S / L298N) | 역할 | 비고 |
| :--- | :--- | :--- | :--- |
| **GPIO 12** | **IN1** (A-IA) | 좌측 모터 전진 PWM | 부팅 시 Low 상태 유지 권장 |
| **GPIO 13** | **IN2** (A-IB) | 좌측 모터 후진 PWM | SD카드 미사용 시 자유 활용 |
| **GPIO 14** | **IN3** (B-IA) | 우측 모터 전진 PWM | SD카드 미사용 시 자유 활용 |
| **GPIO 15** | **IN4** (B-IB) | 우측 모터 후진 PWM | 부팅 시 출력 확인 |
| **GND** | **GND** | 공통 그라운드 (Common GND) | **반드시 배터리/ESP32 GND 연결** |
| **5V** | **VCC** (5V OUT) | ESP32-CAM 전원 공급 | 안정적인 5V 2A 이상 권장 |

> [!CAUTION]
> **전원 분리 및 공통 접지(Common GND) 원칙**:
> 1. 모터 구동용 배터리(예: 18650 2셀 = 7.4V)를 L298N VMS(모터 전원)에 넣고, L298N의 5V 레귤레이터 출력핀을 ESP32-CAM 5V에 인가할 수 있습니다.
> 2. **9V 사각 건전지는 절대 금지!** (전류 부족으로 ESP32 WiFi 기동 시 전압 강하로 무한 재부팅 발생). 18650 충전지 2개(7.4V) 또는 보조배터리(5V 2A 이상)를 사용하세요.
> 3. 모든 전원의 **GND선은 하나로 묶여야(Common GND)** 신호 노이즈가 발생하지 않습니다.

## 2. 아두이노 우노 + L298N 모터 드라이버 결선 (보조 옵션)

### [Arduino Uno ↔ L298N]
| Arduino Uno 핀 | L298N 모터 드라이버 | 역할 |
| :--- | :--- | :--- |
| **D5 (PWM)** | **ENA** (점퍼캡 제거 후 연결) | 좌측 모터 속도 제어 |
| **D6** | **IN1** | 좌측 모터 정회전 |
| **D7** | **IN2** | 좌측 모터 역회전 |
| **D8** | **IN3** | 우측 모터 정회전 |
| **D9** | **IN4** | 우측 모터 역회전 |
| **D10 (PWM)**| **ENB** (점퍼캡 제거 후 연결) | 우측 모터 속도 제어 |
| **GND** | **GND** | 공통 그라운드 |

## 3. ESP32-CAM 프로그램 업로드 시 주의사항 (FTDI / USB-TTL 모듈 사용 시)
1. **GPIO 0과 GND 쇼트(연결)**: 다운로드 모드 진입용 (업로드 시 반드시 연결).
2. **업로드 직전 리셋**: Arduino IDE에서 `Connecting...` 문구가 뜰 때 ESP32-CAM의 RST 버튼 1회 클릭.
3. **업로드 완료 후**: GPIO 0과 GND 연결 해제 후 RST 버튼 클릭해야 정상 실행됨.
