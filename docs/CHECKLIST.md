## 3. 제출 전 남은 일
1. `[팀명]` `[팀장명]` `[팀원명]` `[역할]` `[발표자]` 기입 → `tools/docs_build`에서 `npm run all` → `python tools/make_final.py`.
2. 시연 영상 촬영·편집(3분 이내, 5 Mbps) → 링크를 콘티 상단 표에 기입.
3. 촬영 캡처 4장 `docs/assets/cap_*.jpg` → 재빌드.
4. 신청서 최종본 준비 → 패키징: `tools/package_submission.ps1 -LeaderName <팀장명> -ApplicationPath <신청서> -VideoPath <영상>`.
5. GitHub 저장소 공개 전환 확인 (Settings → Change visibility → Public).
