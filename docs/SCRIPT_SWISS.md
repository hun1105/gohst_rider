### [Slide 1] 표지 (5초)
- **동작**: 인사 후 바로 넘김.
- **대본**: "국립한국해양대학교 [팀명]입니다. 멈추고, 알리고, 사람이 빼내는 AGV 피지컬 AI를 발표하겠습니다."

### [Slide 2] 문제 (25초)
- **강조**: 숫자 세 개를 손으로 하나씩 짚는다. 23억 원은 "대기업을 포함한 평균"이라고 꼭 말한다.
- **대본**: "공장은 생각보다 자주 멈춥니다. 2025년 조사에서 제조업 응답자의 절반 가까이가 일주일에 6번에서 10번 멈춘다고 답했습니다. 한 번 멈추면 생산을 다시 올리기까지 평균 81분이 걸리고, 대기업을 포함한 평균 비용은 시간당 약 23억 원입니다. AGV가 멈췄을 때 사람이 현장까지 걸어가는 시간이 바로 이 81분을 늘립니다."

### [Slide 3] Agent — 목표 · 역할 · 핵심기능 (60초)
- **강조**: 제목 문장을 천천히. 핵심기능 네 개는 번호를 말하며 짚는다.
- **대본**: "저희 에이전트의 원칙은 하나입니다. 판단은 로봇이, 결정은 사람이 합니다. 목표는 AGV 두 대를 운용하면서 협착과 충돌을 0건으로 만들고, 막혔을 때 현장 출동 없이 원격으로 빼내는 것입니다. 핵심기능은 네 가지입니다. 첫째, 앞 0.35미터나 다른 AGV 0.3미터 안에 들어오면 즉시 멈춥니다. 둘째, 라이다로 빠져나갈 방향을 계산해 카메라 영상 바닥에 그려 줍니다. 셋째, 관제 지도에서 로봇을 누르면 그 로봇의 VR 운전석으로 바로 들어갑니다. 넷째, 두 대가 각자 순찰하다 만나면 둘 다 멈추고, 사람이 한 대를 골라 비켜줍니다. 로봇이 스스로 후진하거나 다시 출발하는 일은 없습니다. 움직이는 결정은 항상 사람이 합니다."

### [Slide 4] 구조 ① Workflow (30초)
- **강조**: 노란 블록(5·6)을 가리키며 "여기부터 사람".
- **대본**: "흐름은 여섯 단계입니다. 순찰하다가 라이다와 바퀴 회전 정보로 위험을 감지하면, 안전 게이트가 전진을 막고, 빠져나갈 경로를 계산합니다. 여기까지 네 단계는 로봇이 스스로 합니다. 노란색 두 단계, VR로 들어가 빼내고 순찰을 다시 맡기는 일은 사람이 합니다. 위험한 결정을 로봇에게 맡기지 않는 구조입니다."

### [Slide 5] 구조 ② AI · Tool · Data · Memory (30초)
- **강조**: "LLM 없이"에서 잠깐 멈춘다.
- **대본**: "AI는 대형 언어 모델이 아니라 라이다 기하 계산입니다. 72개 방향의 여유 공간을 재서 가장 넓고 덜 도는 방향을 고릅니다. 같은 입력이면 항상 같은 판단이 나와 안전 장치에 맞습니다. 도구는 로봇 운영체제 ROS의 주행 명령과 센서, 그리고 Unity와 메타 퀘스트입니다. 데이터는 실시간 센서만 쓰고, 로봇별 상태와 정지 원인, 운행 이력을 기억합니다."

### [Slide 6] 실제 시연 ① (2분 15초, 라이브)
- **진행**: 이 장을 띄운 채 4분할 화면(관제 맵 · Quest 콕핏 · 릴레이 터미널 · 실물 캠)으로 전환. 라이브 불가 시 `VIDEO_SCRIPT_3MIN.md` 2~4막 영상 재생.
- **큐 시트**

| 시각 | 누가 | 동작 | 발표자 멘트 요지 |
|---|---|---|---|
| 0:00 | 발표자 | 4분할 화면 전환 | "실물 두 대로 보여드리겠습니다." |
| 0:10 | 관제 | 관제 PC에서 `R` | "두 대가 시작 위치를 맞추고 직진합니다." |
| 0:30 | — | 두 대 접근 → 정지 | "0.3미터 안에서 둘 다 멈췄습니다. 지도가 빨갛게, 터미널에 STUCK." |
| 0:50 | 작업자 역 | 한 대 앞에 손·상자 | "사람이 앞을 막으면 0.35미터에서 전진이 0이 됩니다." |
| 1:05 | 관제 | 관제 맵에서 그 로봇 클릭 | "누르는 순간 그 로봇의 VR 운전석으로 들어갑니다." |
| 1:20 | VR | 그립 쥐고 우 스틱 후진, 좌 스틱 선회 | "바닥에 길이 그려지고, 돌 쪽 손이 떨립니다." |
| 1:45 | VR | 그립 놓기 | "손을 떼면 즉시 멈춥니다. 속도는 0.15를 넘지 않습니다." |
| 2:00 | 관제 | `R` | "사람이 승인하면 순찰로 돌아갑니다." |

- **대본**: "이제 실물로 보여드리겠습니다. 관제석에서 R을 누르면 두 대가 시작 위치를 맞추고 직진합니다. 서로 0.3미터 안으로 들어오자 둘 다 멈췄고, 지도와 터미널에 바로 표시됩니다. 이번에는 사람이 앞을 막아 보겠습니다. 0.35미터 안에서 전진 명령이 0이 됩니다. 관제 지도에서 이 로봇을 누르면 VR 운전석으로 바로 들어갑니다. 영상 바닥에 빠져나갈 길이 그려지고, 돌아야 할 쪽 손이 떨립니다. 그립을 쥔 채 오른쪽 스틱으로 후진, 왼쪽 스틱으로 회전합니다. 그립을 놓으면 즉시 멈추고, 아무리 밀어도 초속 0.15미터를 넘지 않습니다. 다시 R을 누르면 순찰로 돌아갑니다."

### [Slide 7] 실제 시연 ② 화면 (15초)
- **강조**: 빨간 띠 → 초록 띠 → 화살표 순서로 짚는다.
- **대본**: "방금 콕핏 화면입니다. 빨간 띠는 왜 멈췄는지, 초록 띠는 어디로 빠져나갈지, 화살표는 어느 쪽으로 돌지를 알려 줍니다. 조종하는 사람은 판단 근거를 보면서 움직입니다."

### [Slide 8] 성과 (30초)
- **강조**: 위 두 숫자(81분 · 78종)를 먼저, 아래 네 항목은 제목만 빠르게. "81분이 0분이 된다"고 말하지 않는다.
- **대본**: "성과입니다. 공장이 멈추면 생산을 다시 올리기까지 평균 81분이 걸리는데, 저희는 관제석에서 VR로 바로 개입하니 그중 현장까지 오가는 시간이 사라집니다. 또 장애물, AGV 충돌, 통신 끊김 같은 위험 상황 78가지를 자동으로 재현해 모두 통과했습니다. 그 밖에 위험하면 전진을 막고 스스로 후진하지 않으며, 멈춘 이유와 빠져나갈 길을 화면에 보여주고, 관제사 한 명이 두 대를 운용하며, 통신이 끊기면 스스로 멈춥니다. 실제 현장의 총 복구 시간은 파일럿 라인에서 측정할 계획입니다."

### [Slide 9] 발전계획 ① 현장 적용 전 보완 (15초)
- **대본**: "현장에 들이기 전에 다섯 가지를 더하겠습니다. 첫째, 시중 AGV와 건설기계에 바로 붙일 수 있도록 제어기·PLC와 정지·재개 신호를 주고받게 하겠습니다. 둘째, 카메라 객체 인식으로 멈춘 이유가 사람인지 물건인지 구분하겠습니다. 셋째, 깊이 카메라로 2D 라이다의 높이 사각을 메우고, 넷째, 바닥 마커를 읽어 위치 오차를 자동으로 바로잡고, 다섯째, 운행 로그의 정지 원인과 빈도를 분석해 고장 징후를 원격으로 점검하겠습니다."

### [Slide 10] 발전계획 ② 비즈니스모델 · 맺음말 (15초 → 30초 권장)
- **강조**: 가운데 노란 칸(관제 구독)이 핵심. 경쟁사 표는 "유리" 열만 읽고 "불리"는 "앞 장 계획이 보완"으로 한 문장 처리.
- **대본**: "비즈니스 모델은 세 갈래입니다. 첫째, AGV와 건설기계 제조사, SI 업체에 소프트웨어를 대당 라이선스로 넣습니다. 브레인 코프가 제조사에 자율주행 OS를 넣는 방식으로 2023년 구독 로봇 3만 대를 넘겼습니다. 둘째, 핵심은 현장 구독입니다. 로봇 한 대당 월 구독으로 관제, 원격 개입, 로그 원격 점검을 제공하고, 업계 원격 운용 가격은 로봇당 월 200에서 900달러입니다. 셋째, 관제 인력이 없는 현장에는 원격 개입을 시간당으로 대행합니다. 다만 사람 운전만 팔던 팬텀 오토는 2024년 문을 닫았기 때문에 부가 서비스로만 둡니다. 경쟁사와 비교하면, 정지 판단이 로봇 쪽에 있고 VR로 직접 빼낸다는 점이 강점이고, 규모와 인증은 약점이라 앞 장의 계획으로 보완하겠습니다. 로봇은 멈추고 알리고, 판단은 사람이 내립니다. 감사합니다."

| 1 | LLM을 안 쓰는데 AI Agent가 맞나? | 목표·계획·판단·도구 사용·기억·피드백 6요소를 갖춘 에이전트. 판단은 라이다 기하 추론. 안전 장치는 같은 입력에 같은 판단이 나와야 해서 일부러 LLM을 쓰지 않음. |

| 10 | VR이 꼭 필요한가? 모니터로는? | 모니터로도 조종 가능. VR은 1인칭 시야와 양손 조작, 손 방향 진동으로 좁은 곳 탈출을 직관적으로 함. |
