### [Slide 1] 표지
- **구성**: 대학부 · 32 제조 피지컬 AI 칩, 제목 "멈추고, 알리고, 사람이 빼낸다", 부제, 국립한국해양대학교 [팀명] · [발표자], 실물 2대 사진
- **대본 (10초)**: "국립한국해양대학교 [팀명]입니다. 막히면 멈추고 사람을 불러 VR로 빼내는 AGV 피지컬 AI를 발표하겠습니다."

### [Slide 2] 배경 및 문제
- **구성**: 통계 카드 3장 — 끼임 53%(부딪힘 34%, KOSHA 2011~2020) / 2024년 끼임 사망 66명(+22.2%, 고용노동부) / 라인 정지 시간당 최대 230만 달러(Siemens 2024)
- **대본 (20초)**: "산업용 로봇 사고의 53%가 끼임, 34%가 부딪힘입니다. 2024년 끼임으로 66명이 숨졌습니다. 라인이 멈추면 자동차 공장은 시간당 최대 230만 달러를 잃습니다. 사고와 정지 비용은 사람과 AGV가 같은 통로를 쓰는 바로 그 지점에서 생깁니다."

### [Slide 3] 보급형 AGV의 3대 한계
- **구성**: 3열 — 높이 사각지대 / 자율 후진의 역설 / 물리적 출동
- **대본 (20초)**: "보급형 AGV는 2D 라이다 한 평면만 봅니다. 막혔을 때 뒤를 못 보는 로봇이 스스로 물러나면 뒤쪽 사람을 칠 수 있어 결국 비상정지하고, 관리자가 걸어올 때까지 통로가 막힙니다."

### [Slide 4] 솔루션 개요
- **구성**: STOP → NOTIFY → TAKE OVER 3단 흐름
- **대본 (25초)**: "저희 Agent는 위험하면 먼저 멈추고, 왜 멈췄는지와 어디로 빠지면 되는지를 화면에 그립니다. 관제사가 지도에서 그 로봇을 누르면 VR 착용자가 운전석으로 바로 들어가 빼낸 뒤 순찰을 다시 맡깁니다."

### [Slide 5] 시스템 아키텍처
- **구성**: 아키텍처 도식 — TurtleBot3 2대(ROS 1·ROS 2, LDS-02, Pi Camera) ↔ rosbridge ↔ Python 릴레이(안전 게이트·경로 플래너) ↔ Unity(PC 관제 맵 · Quest 콕핏)
- **대본 (30초)**: "두 대의 TurtleBot3는 ROS 1과 ROS 2로 서로 다르지만 rosbridge로 한 릴레이에 묶었습니다. 릴레이는 초당 20번 안전 게이트를 통과한 속도 명령만 로봇에 보내고, Unity는 PC에 관제 지도, 헤드셋에 1인칭 화면을 따로 보여줍니다."

### [Slide 6] AI Agent 6요소
- **구성**: 에이전트 루프 도식 + 6요소 표
- **대본 (30초)**: "목표는 협착·충돌 0건과 무사고 탈출입니다. 순찰하다 위험을 감지하면 정지하고, 라이다로 탈출 경로를 계산해 사람에게 넘깁니다. 도구는 ROS의 cmd_vel·odom·scan과 카메라, 웹소켓, Unity이고, 로봇별 모드와 정지 원인, 운행 이력을 기억합니다. 결과는 화면과 컨트롤러 진동으로 돌려줍니다."

### [Slide 7] 핵심 알고리즘
- **구성**: 4단계(충돌 가드 / 탈출 방향 / 궤적·선회 추천 / VR 텔레옵) + 실제 plan_escape 계산 도식
- **대본 (30초)**: "전방 0.35미터, 로봇 간 1미터 안이면 멈춥니다. 탈출 방향은 5도 간격 72방향마다 로봇 폭 통로의 여유를 재서 고르고, 곡률이 다른 원호 25개로 추천 궤적을 만들며, 막히면 제자리 선회를 권합니다. 조종은 그립을 쥐어야만 되고, 돌아야 할 쪽 손이 떨립니다."

### [Slide 8] 정량 실증 결과
- **구성**: 큰 수치 3개(자동 시험 73/73, 실물 2대, 제어 20 Hz·영상 15.7 fps) + TC-01~05 표
- **대본 (30초)**: "대회 시험 항목 5개를 모두 확인했습니다. 가짜 rosbridge로 실물과 같은 메시지를 흘려 73개 항목을 자동 시험해 모두 통과했고, 실물에서는 0.35미터 정지, Quest와 키보드 주행, VR 화면 전환을 확인했습니다."

### [Slide 9] 산업·경제적 기대효과
- **구성**: 좌 피지컬 AI 차별성 3개, 우 산업 파급력 3개 (개조형 확산 / 1인 다대 관제 / 조선·항만·제조 확장)
- **대본 (25초)**: "답을 말하는 AI가 아니라 바퀴를 멈추고 움직이는 AI입니다. 2D 라이다와 카메라만 써서 기존 보급형 AGV에 소프트웨어로 붙일 수 있고, 관제사 한 명이 여러 대를 보다가 막힌 로봇에만 들어가 현장 출동을 줄입니다."
