### [Slide 1] 표지
- **구성**: 대학부 · 분야 32 칩, 제목 "멈추고, 알리고, 사람이 빼낸다", 부제, 국립한국해양대학교 [팀명] · [발표자]
- **대본 (5초)**: "국립한국해양대학교 [팀명]입니다. 막히면 멈추고, 알리고, 사람이 VR로 빼내는 AGV 피지컬 AI를 발표하겠습니다."

### [Slide 2] 문제 — 누구의 어떤 문제
- **구성**: WHO 3카드(현장 작업자 · 관제사·관리자 · 공장) + 근거 3카드(끼임 53% KOSHA, 2024 끼임 사망 66명 +22.2% 고용노동부, 라인 정지 시간당 최대 $2.3M Siemens) + 보급형 AGV 한계 3줄
- **대본 (25초)**: "AGV와 같은 통로를 쓰는 작업자는 부딪히고 끼입니다. 산업용 로봇 재해의 53%가 끼임이고, 2024년 끼임 사망자는 66명이었습니다. 관제사는 AGV가 멈출 때마다 현장으로 걸어가야 하고, 그동안 라인이 서면 자동차 공장은 시간당 최대 230만 달러를 잃습니다. 보급형 AGV는 한 평면만 보고, 뒤를 못 봐 스스로 물러나지 못합니다."

### [Slide 3] Agent 설명 — 목표 · 역할 · 핵심기능
- **구성**: 목표 카드, 역할 분담(Agent: 감시·정지·원인·경로 추천 / 사람: 선택·VR 조종·재개 승인), 핵심기능 4(STOP · NOTIFY · TAKE OVER · MULTI-AGV)
- **대본 (60초)**: "목표는 AGV 두 대를 운용하면서 협착과 충돌을 0건으로 만들고, 막혔을 때 현장 출동 없이 원격으로 빼내는 것입니다. 역할은 나눴습니다. 에이전트는 감시하고, 멈추고, 왜 멈췄는지와 빠져나갈 경로를 계산합니다. 움직이는 결정은 사람이 합니다. 그래서 자동 후진도, 자동 재개도 없습니다. 핵심기능은 네 가지입니다. 첫째, 전방 0.35미터나 로봇 간 0.3미터 안이면 전진을 막습니다. 둘째, 라이다 72방향으로 탈출 경로를 찾아 영상 바닥과 지도에 그리고, 돌아야 할 쪽 손을 진동시킵니다. 셋째, 관제 지도에서 로봇을 누르면 그 로봇의 VR 운전석으로 바로 들어갑니다. 넷째, 두 대가 각자 순찰하다 만나면 둘 다 멈추고, 사람이 한 대를 비켜줍니다."

### [Slide 4] 구조 ① Workflow
- **구성**: 6단계 흐름(AUTO 순찰 → 위험 감지 → 정지 게이트 → 탈출 경로 → VR 개입 → AUTO 재개), 하단 조건 · 방법 · 결과
- **대본 (30초)**: "흐름은 여섯 단계입니다. 순찰하다 라이다와 오도메트리로 위험을 감지하면 정지 게이트가 전진을 막고, 탈출 경로를 계산합니다. 여기까지가 에이전트입니다. 방법은 5도 간격 72방향마다 로봇 폭 통로의 여유를 재고, 여유는 크고 회전은 적은 방향을 고르는 것입니다. 그 다음 VR 개입과 재개는 사람이 합니다."

### [Slide 5] 구조 ② AI · Tool · Data · Memory
- **구성**: 아키텍처 그림 + 4카드(AI 기하 추론·LLM 미사용 / Tool ROS·카메라·WebSocket·Unity·Quest / Data 실시간 센서 / Memory 로봇별 상태·원인·이력)
- **대본 (30초)**: "ROS 1과 ROS 2로 나뉜 터틀봇 두 대를 초당 20회 도는 파이썬 릴레이가 묶습니다. AI는 대형 언어 모델이 아니라 라이다 기하 추론이라 매 주기 같은 입력에 같은 판단을 냅니다. 도구는 ROS의 cmd_vel, odom, scan과 카메라, Unity, 퀘스트이고, 로봇별 모드와 정지 원인, 운행 이력을 기억합니다. 안전 게이트를 통과한 속도만 바퀴로 나갑니다."

### [Slide 6] 실제 시연 ① 입력 → 판단 → Tool → 결과
- **구성**: 5막 표(자율 순찰 · 정지·알림 · VR 개입 · 안전장치 · 재개) × 입력/판단/Tool 호출/결과. 화면 4분할(관제 맵 · 콕핏 · 터미널 · 실물 캠)
- **진행**: 이 슬라이드를 띄운 채 라이브 시연 (약 2분 15초). 라이브 불가 시 `VIDEO_SCRIPT_3MIN.md` 2~4막 영상 재생.
- **대본 (2분 15초, 시연과 함께)**: "이제 실물로 보여드리겠습니다. 관제 PC에서 R을 누르면 두 대가 시작 위치를 맞추고 초당 0.1미터로 직진합니다. 서로 0.3미터 안으로 들어오자 둘 다 멈췄고, 지도에 적색으로, 터미널에 STUCK으로 찍힙니다. 이번엔 작업자가 앞을 막아보겠습니다. 0.35미터 안에서 전진 지령이 0이 됩니다. 관제 지도에서 이 로봇을 누르면 VR 운전석으로 바로 들어갑니다. 영상 바닥에 빠져나갈 길이 그려지고, 돌아야 할 쪽 손이 진동합니다. 그립을 쥔 채 오른쪽 스틱으로 후진, 왼쪽 스틱으로 선회합니다. 그립을 놓으면 즉시 멈추고, 아무리 밀어도 0.15미터를 넘지 않습니다. 다시 R을 누르면 순찰로 돌아갑니다."

### [Slide 7] 실제 시연 ② 화면 근거
- **구성**: 콕핏 영상 위 정지 배너·경로 띠, 관제 맵 적색 경고, plan_escape 계산 그림, 화면별 의미(COCKPIT · GOD-VIEW · TERMINAL)
- **대본 (15초)**: "방금 화면을 정리하면, 콕핏에는 경로와 정지 배너, 관제 맵에는 적색 경고와 정지 원인, 터미널에는 판단과 도구 호출 기록이 남습니다. 멈춘 이유와 빠져나갈 길이 모두 보입니다."

### [Slide 8] 성과 — Before / After · 검증 · 효과
- **구성**: Before(비상정지·현장 출동·기록 없음) / After(전진만 차단·원격 탈출·원인 기록), 수치(78/78 자동 시험, 10회 반복 무결점, 300초 부하 안전 위반 0건, 20 Hz), 사용자 검증(사실 그대로), 효과
- **대본 (30초)**: "기존 AGV는 멈추면 사람이 걸어가야 풀렸습니다. 이제는 전진만 막고, 관제석에서 클릭 한 번으로 VR로 빼냅니다. 자동 시험 78개를 모두 통과했고, 10회 반복과 300초 부하에서 안전 위반은 0건이었습니다. 사용자 검증은 팀원이 관제사와 조작자 역할로 실물 두 대에서 확인했고, 외부 사용자 평가와 현장 정지 시간 측정은 다음 단계입니다."

### [Slide 9] 발전계획 ① 현장 적용 전 보완점
- **구성**: 한계 5행(높이 사각 · 위치 누적 오차 · 통신 두절 · 보안 · 효과 실측) × 현재 상태 / 보완 방법
- **대본 (15초)**: "현장에 들이기 전 고칠 점도 분명합니다. 높이 사각은 깊이 카메라로, 위치 오차는 SLAM으로 보완하고, 로봇 측 정지 감시와 통신 인증을 붙인 뒤 파일럿 라인에서 정지 시간을 실측하겠습니다."

### [Slide 10] 발전계획 ② 기대효과 · 비즈니스모델 · 결론
- **구성**: BM 3안(개조 패키지 · 관제 구독 · 원격 개입 센터, 구상 단계), 시장 $22B(LogisticsIQ 2024), 기대효과 3, 맺음말
- **대본 (15초)**: "사업은 기존 AGV에 얹는 개조 패키지와 관제 구독, 여러 현장을 한 자리에서 복구하는 원격 개입 서비스로 구상합니다. 로봇은 멈추고 알리고, 판단은 사람이 내린다. 감사합니다."
