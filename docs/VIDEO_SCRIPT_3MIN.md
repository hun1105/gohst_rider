## 0. 촬영 준비

### 0.1 실행 (순서·설명: `launch/README.md`)
```powershell
launch\start_tb1_robot.bat      # TB1: roscore + rosbridge + bringup (ROS 1), 172.30.1.58
launch\start_tb2_robot.bat      # TB2: rosbridge + 카메라 + bringup (ROS 2), 172.30.1.28
launch\run_relay_tb1_tb2.bat    # tb1=TB1, tb2=TB2(카메라), 두 대 각각 AUTO
```
Unity Play → PC 상단 배너, 사이드바 `LINK ONLINE`, 로봇 카드 2개 확인 → 로봇을 시작 자리에 두고 첫 `R` (위치 자동 재설정).

### 0.2 화면 구성 (4분할)
```
+-----------------------------+-----------------------------+
| [1] PC 관제 맵 + 사이드바     | [2] Quest HMD 콕핏 (미러)     |
|  (로봇 상태·정지 원인)        |  (영상 경로 띠·선회 화살표)   |
+-----------------------------+-----------------------------+
| [3] 릴레이 터미널 로그        | [4] 실물 로봇 주행 캠          |
|  ([AUTO]·[INTERLOCK] 이벤트) |  (바퀴·정지·후진 식별)         |
+-----------------------------+-----------------------------+
```
- 4개 화면 동시 녹화, 박수 1회로 싱크. [3] 터미널은 입력 → 판단 → Tool 호출의 증거 (별지 2 요구). 장면마다 하단에 4단계 칩(입력 → 판단 → Tool → 반응)과 TC 번호 자막.

### 0.3 현장 배치
| 항목 | 내용 |
|---|---|
| 출발 배치 | 두 로봇 마주 보기, 범퍼 사이 Galaxy S20 FE 세로 6개(0.959 m, 중심 1.10 m). 배회 반경 0.6 m, 만남 기준 0.3 m |
| 장애물 | 작업자 역 1명 (3막 전방 접근), 필요 시 상자 1개 |
| 인원 | 관제사(PC), VR 착용자, 비상정지 담당(Space·로봇 전원 스위치 옆) |

## 1. 타임라인

### 1막. 문제 제기 (0:00 ~ 0:30)
- **화면**: 검은 바탕 수치 카드 3장 → 실물 AGV 2대가 같은 통로를 지나는 현장 컷.
- **자막**: `산업용 로봇 재해 끼임 53% · 부딪힘 34% (KOSHA, 2011~2020)` / `2024년 끼임 사망 66명, +22.2% (고용노동부)` / `라인 정지 비용 시간당 최대 230만 달러 (Siemens 2024)`
- **나레이션**: "산업용 로봇 사고의 절반 이상은 끼임, 3분의 1은 부딪힘입니다. 2024년 끼임으로 66명이 숨졌습니다. 보급형 AGV는 2D 라이다 한 줄로 세상을 보고, 막히면 멈춘 채 사람이 걸어올 때까지 라인을 세웁니다."

### 2막. 관제 맵과 AUTO 순찰 (0:30 ~ 1:10) · TC-04 · TC-02
- **칩**: `입력 R → 판단 로봇 간 0.3m 감시 → Tool /cmd_vel 직진 → 반응 실물 2대 정지`
- **화면**: `R` → 두 대 위치가 시작 자리로 맞춰진 뒤 0.10 m/s로 서로를 향해 직진 → 가까워지면 **정지**, 지도에서 적색, 사이드바 카드에 정지 원인 (`LIDAR OBSTACLE` 또는 `COLLISION RISK`), 터미널에 `[AUTO] … STUCK`.
- **자막**: `AUTO 직진 0.10 m/s · 전방 0.35m · AGV 간 0.3m 정지`
- **나레이션**: "두 대의 AGV가 자율 주행을 시작합니다. 앞에 장애물이 0.35미터 안으로 들어오거나 서로 너무 가까워지면, 스스로 판단해 멈추고 관제사를 부릅니다."

### 3막. 돌발 협착 위험 → 정지·알림 (1:10 ~ 1:50) · TC-01 · TC-05
- **칩**: `입력 작업자 0.35m 진입 → 판단 LiDAR 인터록 → Tool /cmd_vel 0 → 반응 실물 정지·적색 경고`
- **화면**: 작업자 역이 순찰 중인 TB2 앞 0.35m 안으로 들어섬 → 즉시 정지. 관제 맵 적색 차체 점멸 + 위험 원판, 콕핏 영상 상단 적색 배너 `STOPPED: LIDAR OBSTACLE`, 바닥에 녹색 경로 띠 또는 선회 곡선 화살표, 하단 `ESCAPE: TURN LEFT, THEN GO`.
- **자막**: `자동 후진 없음 — 정지 후 사람에게 판단을 넘김 · 경로는 LiDAR로 계산`
- **나레이션**: "작업자가 다가오자 로봇은 그 자리에서 멈춥니다. 뒤를 못 보는 로봇이 스스로 물러나는 것 자체가 위험하기 때문입니다. 대신 왜 멈췄는지와 어디로 빠지면 되는지를 화면에 그립니다."

### 4막. 관제 클릭 → VR 즉시 개입 → 수동 탈출 (1:50 ~ 2:30) · TC-03 · TC-05
- **칩**: `입력 지도 클릭·그립+스틱 → 판단 그 로봇만 MANUAL·전진 차단 → Tool SELECT_ROBOT·/cmd_vel → 반응 실물 후진 탈출`
- **화면**:
  1. 관제사가 PC 맵에서 빨간 로봇 클릭 → 착용자 HMD가 애니메이션 없이 바로 그 로봇 콕핏으로 전환.
  2. 그립을 쥔 채 우 스틱 위 → 바퀴 안 움직임(전진 차단), 컨트롤러 진동. 돌아야 할 쪽 손만 진동.
  3. 우 스틱 아래 후진 + 좌 스틱 선회로 녹색 경로를 따라 빠져나옴 → 배너 사라짐.
  4. God-View 복귀 → `Y`/`R`로 AUTO 재개.
- **자막**: `현장 출동 없이 관제석에서 바로 · 그립 데드맨 · 후방 0.2m 라이다 가드`
- **나레이션**: "관제사가 지도에서 멈춘 로봇을 누르면 VR 착용자가 그 로봇의 운전석으로 바로 들어갑니다. 전진은 막혀 있고 후진과 회전만 됩니다. 손을 떼면 즉시 멈춥니다. 빠져나온 뒤 버튼 하나로 순찰을 다시 맡깁니다."
- **대체 컷 (VR 불가 시)**: 같은 흐름을 PC `WASD`로, 자막 `PC 원격 조작`.

### 5막. 안전 설계와 파급력 (2:30 ~ 2:50) · TC-04
- **칩**: `입력 Unity 종료 → 판단 연결 해제 → Tool 정지 지령 → 반응 실물 정지`
- **화면**: 주행 중 Unity 창 닫기 → 실물 정지 → 결과 카드 (`자동 시험 78/78 · 실물 TurtleBot3 2대 · 3D LiDAR 없이`).
- **나레이션**: "통신이 끊기면 로봇은 바로 멈춥니다. 2D 라이다와 카메라, 정지를 우선하는 안전 게이트, 그리고 VR 원격 개입으로, 보급형 AGV를 사람과 함께 일하는 피지컬 AI로 바꿉니다. 감사합니다."
